# Challenge X Portfolio

Challenge X is a hybrid, hackathon-style, eight-week innovation program that connects students with organizations to solve real-world problems across healthcare, finance, technology, engineering, and beyond. 

This repository houses the complete engineering architecture for two autonomous robotic systems developed during the competition.

## Featured Projects

* **[Autonomous FMCW GPR Wildlife Detection & Relocation Rover](./wildlife-detection-rover/)**
  An all-terrain sub-surface scanning rover designed to locate buried native Virginia Eastern Woodland Box Turtles on active construction sites using a custom FMCW radar architecture.

* **[Untethered Wireless Video Communication Pipe Inspection Crawler](./pipe-inspection-crawler/)**
  A multi-segment, articulated robotic crawler featuring a mechanical dropped relay mechanism designed to maintain multi-hop wireless video feeds inside highly attenuating municipal sewer systems.
