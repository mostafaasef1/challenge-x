# Challenge X Portfolio

Welcome to the portfolio for the Challenge X innovation program. This repository hosts two distinct autonomous robotic systems developed to solve complex, real-world engineering problems.

## Featured Projects

* **Autonomous FMCW GPR Wildlife Detection & Relocation Rover:-**
  An all-terrain sub-surface scanning rover designed to locate buried native Virginia Eastern Woodland Box Turtles on active construction sites using a custom FMCW radar architecture.

* **Untethered Wireless Video Communication Pipe Inspection Crawler:-**
  A multi-segment, articulated robotic crawler featuring a mechanical dropped relay mechanism designed to maintain multi-hop wireless video feeds inside highly attenuating municipal sewer systems.
